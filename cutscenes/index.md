# Катсцены — как рисовать и добавлять

## Что это

Катсцены — SVG-файлы с расширением `.cut`. Игра паузит и ждёт «Продолжить».

## Формат

Обязательно:
- `viewBox="0 0 800 400"` (НЕ менять).
- `<metadata>{...json...}</metadata>` (НЕ удалять) — заголовок и реплики.

Остальное — любое: `<rect>`, `<path>`, `<g>`, `<text>`, `<image>`.

## Архитектура: имя файла = момент показа

~~~
cutscenes/
  0-0.cut ... 0-99.cut     - пролог (перед стартом игры)
  1-0.cut ... 1-99.cut     - перед 1-м уровнем
  ...
  20-0.cut ... 20-99.cut   - перед 20-м уровнем
  f0-0.cut ... f0-99.cut   - проигрыш (трибунал)
  f1-0.cut ... f1-99.cut   - победа (все 20 уровней)
  f2-0.cut ... f2-99.cut   - пасхалка (мир)
  f3-0.cut ... f3-99.cut   - стена пала
  f4-0.cut ... f4-99.cut   - обычный game over
~~~

Игра сканирует папку: `N-0.cut`, `N-1.cut`, ... до первого отсутствующего файла. Если `0-3.cut` нет — покажет `0-0`, `0-1`, `0-2`.

## Как добавить катсцену

1. Скопируй любой `.cut` (например `2-0.cut`) и назови `15-0.cut` (перед 15-м уровнем).
2. Перерисуй SVG (кроме `<metadata>`).
3. В `<metadata>` поменяй `title` и `lines`.
4. Код не трогаешь — игра сама найдёт файл.

Несколько подряд: `5-0.cut`, `5-1.cut`, `5-2.cut` — покажет три штуки перед 5-м уровнем.

## Как убрать

Удали файл. Убрал `2-0.cut` — перед 2-м уровнем катсцены не будет.

## Размеры и сетка

- `viewBox="0 0 800 400"` — соотношение 2:1.
- Меню в игре — не часть катсцены. Верхние 0–30 px оставь пустыми.
